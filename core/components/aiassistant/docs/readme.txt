AI-ассистент каталога для MODX 2.8+ и MODX 3.

Плавающая кнопка открывает чат. Посетитель пишет бюджет, тираж, цвет и повод.
Компонент фильтрует JSON/XML/YML-фид или товары miniShop2 и передаёт модели только подходящие строки.
В ответе — текст, список товаров со ссылками и кнопки «Добавить в корзину» и «Оформить спецификацию».

Провайдеры: demo, OpenAI, YandexGPT, GigaChat и любой OpenAI-совместимый API.
Ключи остаются в системных настройках.

После установки откройте системные настройки пространства имён aiassistant.
aiassistant.debug прячет чат от посетителей и пишет подробный журнал в core/cache/aiassistant/debug.log. Чат остаётся у пользователя, вошедшего в админку.
Подробности — в README репозитория.
